# Voice survey

## About 

The Voice survey app lets you create and share your surveys, these can be voiceonly or even text based surveys

## Running locally in development mode

To get started, just clone the repository and run `yarn && yarn dev`:

    git clone git@gitlab.com:vinignani/voice-survey.git
    yarn
    yarn dev
    
Make sure in .env.local NEXTAUTH_URL=https://localhost:3000
